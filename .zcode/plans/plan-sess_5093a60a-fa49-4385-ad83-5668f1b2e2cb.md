# แผนสร้าง Discord AI Bot (ถาม-ตอบ) ด้วย Node.js

## ภาพรวม
สร้างบอท Discord ตอบคำถามด้วย AI ในโฟลเดอร์ `BOT AI DISCORD` (ตอนนี้ว่างเปล่า) โดย:
- **discord.js v14** + Node.js (เครื่องมี Node 24 แล้ว)
- เรียก AI ผ่าน **OpenAI-compatible API** (`/chat/completions`) ด้วย native `fetch` — ตั้งค่า BASE_URL / API_KEY / MODEL จากไฟล์ `.env` ใช้ได้กับ OpenAI, OpenRouter, Groq, iApp AI ฯลฯ
- บอทตอบ **ทุกข้อความในช่องที่กำหนด** (ระบุ Channel ID ใน `.env`, เว้นหลายช่องได้)
- **จำบทสนทนา** แยกตามช่อง (เก็บข้อความล่าสุด ~20 ทรานแซกชันในหน่วยความจำ รีเซ็ตเมื่อรีสตาร์ท)

## โครงสร้างไฟล์ที่จะสร้าง
```
BOT AI DISCORD/
├── package.json          # ESM, deps: discord.js, dotenv
├── .env                  # ค่า config จริง (สร้างให้เปล่า ๆ พร้อมคอมเมนต์)
├── .env.example          # ตัวอย่าง config
├── .gitignore            # node_modules, .env
├── README.md             # คู่มือตั้งค่าภาษาไทยละเอียด
└── src/
    ├── index.js          # จุดเริ่ม: สร้าง Discord client, ล็อกอิน, ผูก event
    ├── config.js         # โหลด/ตรวจ .env แจ้ง error แบบเข้าใจง่าย
    ├── ai.js             # เรียก AI (fetch → chat/completions) พร้อม error handling
    ├── memory.js         # Map เก็บประวัติแชทต่อช่อง ตัดข้อความเก่าเกิน limit
    └── messageHandler.js # กรองช่องที่อนุญาต → typing indicator → ถาม AI → ตอบ
```

## การทำงานหลัก
1. มีคนพิมพ์ข้อความในช่องที่อยู่ใน `ALLOWED_CHANNEL_IDS`
2. บอทขึ้นสถานะ "กำลังพิมพ์..." → ประกอบ [system prompt ภาษาไทย, ...ประวัติ, คำถามใหม่] → ยิงไปที่ AI API
3. รับคำตอบ → ส่งกลับ (ตัดข้อความเกิน 2,000 ตัวอักษรเป็นหลายข้อความ)
4. บันทึกคำถาม/คำตอบลงหน่วยความจำของช่องนั้น → ถามต่อเนื่องได้ ("อธิบายเพิ่ม" ก็เข้าใจ)
5. ถ้า AI ล่ม/ผิดพลาด → ตอบข้อความแจ้งเตือนสุภาพ + log รายละเอียดในคอนโซล

## Config ใน .env
- `DISCORD_TOKEN` — โทเคนบอท
- `AI_BASE_URL` — เช่น `https://api.openai.com/v1`
- `AI_API_KEY` — กุญแจของผู้ให้บริการ AI
- `AI_MODEL` — เช่น `gpt-4o-mini`
- `ALLOWED_CHANNEL_IDS` — เช่น `123456,789012`
- `SYSTEM_PROMPT` — ค่าเริ่มต้นเป็นผู้ช่วยตอบภาษาไทย (แก้ได้)
- `HISTORY_LIMIT` — ค่าเริ่มต้น 20

## สิ่งที่ผู้ใช้ต้องเตรียม (มีคู่มือใน README)
1. สร้างแอป + บอทที่ Discord Developer Portal แล้ว **เปิด MESSAGE CONTENT INTENT** (ขั้นตอนนี้สำคัญ บอทจะอ่านข้อความไม่ได้ถ้าไม่เปิด)
2. เชิญบอทเข้าเซิร์ฟเวอร์ (สิทธิ์: View Channels, Send Messages, Read Message History)
3. คัดลอก Channel ID (เปิด Developer Mode แล้วคลิกขวาที่ช่อง)
4. ใส่ค่าใน `.env`

## การตรวจสอบหลังสร้าง
- `npm install` ติดตั้ง dependencies
- `node --check` ทุกไฟล์ยืนยัน syntax ถูกต้อง
- รัน `npm start` โดยยังไม่ใส่ token → ต้องแจ้ง error ภาษาไทยอย่างเป็นระบบ (พิสูจน์ว่า config validation ทำงาน)
- ทดสอบจริงต้องใช้ token + API key ของผู้ใช้ (ผมจะทำให้พร้อมและบอกขั้นตอนที่เหลือให้ชัดเจน)
