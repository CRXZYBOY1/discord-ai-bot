# Discord AI Bot 🤖

บอท Discord ถาม-ตอบด้วย AI ครบทุกฟีเจอร์: ตอบข้อความและรูปภาพในช่องที่กำหนด, เปิดเธรดแยกคำถามให้อัตโนมัติ, เปลี่ยน model ได้ใน Discord, สร้างรูป, สถิติการใช้งาน

เชื่อมต่อกับ AI ใดก็ได้ที่รองรับ **OpenAI-compatible API** เช่น OpenAI, OpenRouter, Groq, iApp AI, Ollama (โมเดลในเครื่อง) ฯลฯ

## ✨ ฟีเจอร์ทั้งหมด

### 💬 การถาม-ตอบ
- **ถาม-ตอบในช่องที่กำหนด** — ตอบทุกข้อความในช่องที่ตั้งค่าไว้ใน `.env`
- **`/ask` ถามได้ทุกช่อง** — คำสั่ง slash ถาม AI ได้ทุกที่ในเซิร์ฟเวอร์
- **ข้อมูลสดอัตโนมัติ 🔎** — ถามเรื่องอากาศ/ข่าว/ราคาทอง-น้ำมัน/ค่าเงิน/หวย/ผลบอล ฯลฯ ในแชทปกติได้เลย บอทจับเองว่าต้องใช้ข้อมูลปัจจุบัน แล้วค้นเว็บ (DuckDuckGo) สรุปพร้อมอ้างอิงให้ — ไม่ต้องใช้คำสั่งพิเศษ (ปรับได้ที่ `SEARCH_MODEL`)
- **จำบทสนทนา** — แยกตามช่อง/เธรด ถามต่อเนื่องได้ เช่น "อธิบายเพิ่ม" หรือ "ยกตัวอย่างหน่อย"
- **คำตอบเป็น Embed** — กล่องสวย มี footer บอก model และเวลา ข้อความยาวตัดเป็นหลายส่วนอัตโนมัติ
- **อ่าน Reply และลิงก์ข้อความ** — reply ถามต่อหรือแปะลิงก์ข้อความ Discord บอทดึงเนื้อหามาเป็นบริบทให้ AI

### 🖼️ มัลติมีเดียและเอกสาร
- **ดูรูปจากแชท (Vision)** — แนบรูปพร้อมคำถาม หรือส่งรูปอย่างเดียวก็อธิบายให้ (สูงสุด 4 รูป/ข้อความ, รูปละไม่เกิน 8MB) — ต้องใช้ vision model
- **`/draw` สร้างรูป** — AI วาดรูปจากคำอธิบาย ส่งกลับเป็นไฟล์แนบในแชท
- **อ่าน PDF และไฟล์เอกสาร** — แนบ PDF/txt/md/csv/json ฯลฯ พร้อมคำถาม บอทอ่านเนื้อหาแล้วตอบ/สรุปให้ (สูงสุด 2 ไฟล์/ข้อความ, ไฟล์ละ 8MB) — ใช้ได้กับ model ข้อความทุกตัว
- **`/compare` เทียบ model** — ถามคำถามเดียวกันให้ 2 model ตอบพร้อมกัน แล้ววางคำตอบเทียบกันในกล่องเดียว

### 🧵 การจัดการบทสนทนา
- **โหมดเธรด** — คำถามแต่ละข้อในช่องหลักเปิดเธรดของตัวเอง ช่องหลักสะอาด ความจำแยกของใครของมัน (เปิด/ปิดได้ที่ `THREAD_MODE`)
- **ลบเธรดอัตโนมัติ** — เธรดที่ไม่มีใครพิมพ์ต่อ 1 ชั่วโมงจะถูกลบทิ้งพร้อมความจำของเธรดนั้น ไม่ต้องมานั่งลบเอง (ปรับเวลาหรือปิดได้ที่ `THREAD_IDLE_DELETE_MINUTES`)
- **`/reset` ล้างความจำ** — เริ่มบทสนทนาใหม่ทันที ไม่ต้องรีสตาร์ท (ผู้ดูแลล้างได้ทุกที่ สมาชิกล้างเธรดของตัวเองได้)

### 🛡️ ป้องกันการใช้งานผิดวิธี
- **กันสแปม** — จำกัดความถี่ต่อคน (`COOLDOWN_SECONDS`) และกันถามซ้อนระหว่างรอคำตอบ (ผู้ดูแลเซิร์ฟเวอร์ไม่โดนจำกัด)

### ⚙️ การบริหารจัดการ
- **`/model` เปลี่ยน model ใน Discord** — ค้นหาจากหลายพัน model แบบสด ๆ ไม่ต้องแก้ไฟล์/รีสตาร์ท (จำค่าที่ตั้งไว้แม้รีสตาร์ท)
- **`/usage` สถิติการใช้งาน** — จำนวนคำถาม ผู้ใช้ token และ model ยอดนิยม ต่อวัน
- **ใช้ AI ได้ทุกเจ้า** — รองรับ OpenAI-compatible API ทั้งหมด เปลี่ยนผู้ให้บริการได้แค่แก้ `.env`
- **ทนทานใช้งานจริง** — ค้นหา model จากแคชได้แม้ AI server ล่ม, รองรับ response แบบ streaming, แจ้ง error เป็นภาษาไทย, log สีสวยพร้อม emoji

## สิ่งที่ต้องเตรียม

- Node.js เวอร์ชัน 18 ขึ้นไป (เช็คด้วยคำสั่ง `node --version`)
- บัญชี Discord และเซิร์ฟเวอร์ที่มีสิทธิ์เชิญบอท
- กุญแจ API ของผู้ให้บริการ AI ที่จะใช้

## ขั้นตอนติดตั้ง

### 1) สร้างบอทใน Discord Developer Portal

1. เข้าไปที่ https://discord.com/developers/applications แล้วกด **New Application** ตั้งชื่อบอท
2. เมนูด้านซ้ายเลือก **Bot**
3. กด **Reset Token** แล้วคัดลอกโทเคนเก็บไว้ (⚠️ ห้ามเปิดเผยโทเคนนี้ให้ใคร — ถ้าหลุดให้กด Reset ใหม่ทันที)
4. ⭐ **สำคัญมาก:** เลื่อนลงมาที่หัวข้อ **Privileged Gateway Intents** แล้ว **เปิดสวิตช์ MESSAGE CONTENT INTENT** — ถ้าไม่เปิดข้อนี้ บอทจะอ่านข้อความไม่ได้เลย
5. กด **Save Changes**

### 2) เชิญบอทเข้าเซิร์ฟเวอร์

1. เมนูด้านซ้ายเลือก **OAuth2** → **URL Generator**
2. ใน Scopes ติ๊กเลือก `bot` **และ** `applications.commands` (ตัวหลังจำเป็นสำหรับคำสั่ง /model)
3. ใน Bot Permissions ติ๊กเลือก:
   - `View Channels`
   - `Send Messages`
   - `Read Message History`
4. คัดลอก URL ที่โผล่ด้านล่าง แล้วเปิดในเบราว์เซอร์ เลือกเซิร์ฟเวอร์ของคุณ กด Authorize

### 3) หา Channel ID ของช่องที่ต้องการให้บอทตอบ

1. ในแอป Discord ไปที่ **ตั้งค่า (Settings) → Advanced → เปิด Developer Mode**
2. คลิกขวาที่ช่อง (channel) ที่ต้องการ → **Copy Channel ID**
3. ทำซ้ำได้กับหลายช่อง (คั่นด้วย `,` ในไฟล์ `.env`)

### 4) ตั้งค่าไฟล์ .env

เปิดไฟล์ `.env` ในโฟลเดอร์นี้ แล้วกรอกค่า:

```env
DISCORD_TOKEN=โทเคนบอทจากขั้นตอนที่ 1
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=กุญแจ API ของคุณ
AI_MODEL=gpt-4o-mini
ALLOWED_CHANNEL_IDS=1234567890123456789
```

ตัวอย่าง `AI_BASE_URL` ของผู้ให้บริการยอดนิยม:

| ผู้ให้บริการ | AI_BASE_URL | ตัวอย่าง AI_MODEL |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `google/gemini-2.0-flash-001` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |
| Ollama (ในเครื่อง) | `http://localhost:11434/v1` | `llama3.1` |

ปรับบทบาทของ AI ได้ที่ `SYSTEM_PROMPT`, ปรับจำนวนข้อความที่จำได้ที่ `HISTORY_LIMIT` และปรับเวลาลบเธรดอัตโนมัติ (นาที) ได้ที่ `THREAD_IDLE_DELETE_MINUTES` (0 = ปิด)

### 5) ติดตั้งและรันบอท

เปิด Command Prompt แล้วรัน:

```
npm install
npm start
```

ถ้าสำเร็จจะขึ้นว่า `✅ บอทออนไลน์แล้วในชื่อ ...` — จากนั้นลองพิมพ์ข้อความในช่องที่กำหนดไว้ บอทจะตอบกลับมาเอง

> 💡 ระหว่างพัฒนาอยากให้บอทรีสตาร์ทเองเมื่อแก้โค้ด ใช้คำสั่ง `npm run dev` แทนได้

## วิธีใช้งาน

- พิมพ์ข้อความอะไรก็ได้ในช่องที่กำหนดไว้ → บอทจะตอบด้วย AI ในกล่อง **embed** พร้อม footer บอก model ที่ใช้
- **ส่งรูปให้บอทดูได้** — แนบรูป (png/jpg/webp/gif) พร้อมพิมพ์คำถาม เช่น "รูปนี้คืออะไร" หรือส่งรูปอย่างเดียว (บอทจะอธิบายรูปให้) รองรับสูงสุด 4 รูปต่อข้อความ ขนาดไม่เกิน 8MB ต่อรูป
  - ⚠️ ต้องใช้ **vision model** (model ที่มองเห็นรูปได้) เช่น `gemini/gemini-3.8-flash` — ถ้าใช้ model ที่ไม่รองรับ บอทจะตอบว่า "ไม่เห็นรูป" ให้เปลี่ยนผ่าน `/model set`
- **โหมดเธรด** (`THREAD_MODE=true`) — คำถามแต่ละข้อในช่องหลักจะเปิด **เธรดของตัวเอง** คำตอบและบทสนทนาต่อ ๆ ไปอยู่ในเธรดนั้น ช่องหลักจึงสะอาด และความจำแยกของใครของมัน (ปิดได้ด้วย `THREAD_MODE=false`)
- **ลบเธรดอัตโนมัติ** — เธรดที่ไม่มีใครพิมพ์ต่อ 1 ชั่วโมง (ปรับได้ที่ `THREAD_IDLE_DELETE_MINUTES`) บอทจะลบทิ้งเอง พร้อมล้างความจำของเธรดนั้น — ทุกข้อความใหม่ในเธรดจะเลื่อนเวลาลบออกไปใหม่ และหลังรีสตาร์ทบอทจะกลับมาจับเวลาเธรดที่ยังเปิดอยู่ต่อจากเดิม
- **อ่าน Reply และลิงก์ข้อความ** — reply ถามต่อจากข้อความไหน หรือแปะลิงก์ข้อความใน Discord บอทจะดึงเนื้อหาข้อความนั้นมาเป็นบริบทด้วย
- **กันสแปม** — คนเดียวถามได้ทุก `COOLDOWN_SECONDS` วินาที (ผู้ดูแลเซิร์ฟเวอร์ไม่โดนจำกัด) และถามซ้อนไม่ได้ระหว่างรอคำตอบ
- บอทจำบทสนทนาล่าสุดของแต่ละช่อง/เธรด (จำนวนตาม `HISTORY_LIMIT`) ดังนั้นถามต่อเนื่องได้ เช่น "อธิบายเพิ่ม" หรือ "ยกตัวอย่างหน่อย"
- ประวัติบทสนทนาเก็บในหน่วยความจำ จะรีเซ็ตเมื่อรีสตาร์ทบอท (หรือใช้ `/reset`)

## คำสั่งทั้งหมด

| คำสั่ง | ใครใช้ได้ | ทำอะไร |
|---|---|---|
| `/ask question:...` | ทุกคน | ถาม AI ได้ในทุกช่อง ไม่ต้องรอบอทในช่องที่กำหนด |
| `/draw prompt:...` | ทุกคน | ให้ AI วาดรูปจากคำอธิบาย (ใช้ `IMAGE_MODEL` ใน .env, มี cooldown แยก) |
| `/compare question:... [model_a] [model_b]` | ทุกคน | ถามคำถามเดียวกันให้ 2 model ตอบพร้อมกัน วางเทียบกันใน embed เดียว (ไม่ระบุ = model ปัจจุบัน vs ค่าเริ่มต้น) |
| `/reset` | ผู้ดูแล / เจ้าของเธรด | ล้างความจำบทสนทนาของช่อง/เธรดนั้น เริ่มคุยใหม่ |
| `/usage` | ทุกคน | ดูสถิติการใช้งาน: จำนวนคำถาม ผู้ใช้ token และ model ยอดนิยม (เก็บใน `data/usage.json`) |
| `/model set/show/reset` | ผู้ดูแลเซิร์ฟเวอร์ | เปลี่ยน model AI ของเซิร์ฟเวอร์ — พิมพ์แล้วค้นหาจากรายชื่อได้ทันที (รองรับหลายพัน model) |

### หมายเหตุเรื่อง /model

- **ทดสอบก่อนเปลี่ยน** — เลือก model แล้วบอทจะยิงคำถามทดสอบสั้น ๆ ให้ model นั้นก่อน ได้ผล ✅ ใช้ได้ หรือ ❌ ใช้ไม่ได้พร้อมสาเหตุ (ถ้าไม่ผ่านจะไม่เปลี่ยน model) — สำคัญมากเพราะรายชื่อจาก server มีตัวที่ประกาศไว้แต่ไม่มี credentials จริงปนอยู่
- **กรองอัตโนมัติ** — model ที่พังล่าสุดภายใน 30 นาทีจะหายจากการค้นหา (พิมพ์ชื่อตรง ๆ ยังเลือกได้ถ้าต้องการบังคับ) ระบบเรียนรู้สถานะจริงจากทุกการใช้งาน ยิ่งใช้ยิ่งแม่น (เก็บใน `data/model-health.json`)
- `/model show` จะโชว์สถานะสุขภาพล่าสุดของ model ปัจจุบันด้วย
- เปลี่ยนแล้วใช้ได้ทันที **ไม่ต้องรีสตาร์ทบอท** และค่าที่ตั้งจะถูกจำไว้ในไฟล์ `data/settings.json` แม้รีสตาร์ท
- การตั้งค่ามีผลทั้งเซิร์ฟเวอร์ (ทุกช่องที่บอทตอบ ใช้ model เดียวกัน)
- รายชื่อในการค้นหามาจาก**แคชในเครื่อง** (`data/models-cache.json`) — บอทตอบไวภายในไม่กี่มิลลิวินาทีและใช้ได้แม้ AI server ล่ม โดยจะรีเฟรชรายชื่อล่าสุดจาก server เบื้องหลังทุก 10 นาทีเมื่อ server ตอบได้
- หมายเหตุ: model แบบ `-thinking` หรือ `-agentic` จะคิดลึกกว่าแต่ตอบช้ากว่า อาจใช้เวลานานจนสถานะ "กำลังพิมพ์" หายไปก่อน ถือเป็นเรื่องปกติ

### หมายเหตุเรื่อง /draw

- ใช้ model จาก `IMAGE_MODEL` ใน .env (ค่าเริ่มต้น `ag/gemini-3.1-flash-image` — ทดสอบแล้วว่าใช้ได้กับ 9router)
- ความพร้อมขึ้นกับ credentials ของ router ณ ตอนนั้น ถ้า provider ล่ม/โดนจำกัด บอทจะแจ้ง error กลับมา ลองใหม่หรือเปลี่ยน IMAGE_MODEL ได้
- รองรับทั้ง image model ที่ตอบผ่าน chat และ endpoint มาตรฐาน `/images/generations`

## รันบอท 24 ชั่วโมง

### ทางเลือก 1: เครื่องนี้ด้วย pm2 (ติดตั้งเรียบร้อยแล้ว)

บอทถูกจัดการด้วย pm2: พังแล้วรีเอง, กินแรมเกินรีเอง, และ**เปิดเครื่องมาพบว่ารันอยู่แล้ว** (ผ่าน pm2-windows-startup)

คำสั่งที่ใช้บ่อย:

| คำสั่ง | ทำอะไร |
|---|---|
| `pm2 status` | ดูสถานะบอท |
| `pm2 logs ai-bot` | ดู log แบบสด (กด Ctrl+C ออก) |
| `pm2 restart ai-bot` | รีสตาร์ท (หลังแก้โค้ดหรือ `.env`) |
| `pm2 stop ai-bot` | หยุดบอท |
| `pm2 start ecosystem.config.cjs` | เริ่มใหม่หลังหยุด |
| `pm2 monit` | หน้าจอมอนิเตอร์ CPU/RAM แบบสด |

⚠️ **ข้อควรระวัง 2 ข้อ:**
1. **ห้ามรัน `npm start` ซ้อนกับ pm2** — บอทจะตอบข้อความซ้ำ 2 ครั้ง (รันได้แค่ instance เดียว)
2. ตั้งค่า Windows **ไม่ให้เครื่อง sleep**: Settings → System → Power & battery → Screen and sleep → เลือก "Never" (หรือรันคำสั่ง `powercfg /change standby-timeout-ac 0`)

### ทางเลือก 2: VPS (Ubuntu) — เสถียรที่สุด

เหมาะเมื่อไม่อยากเปิดคอมตลอดเวลา (RAM 1GB ก็พอ ราว 100-200 บาท/เดือน)

1. ซื้อ VPS Ubuntu 22.04+ แล้ว `ssh root@IP-ของ-VPS`
2. ติดตั้ง Node.js 20:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```
3. คัดลอกโปรเจกต์ขึ้น VPS (git clone หรือ scp -r ทั้งโฟลเดอร์) — **อย่าลืมไฟล์ `.env`**
4. ติดตั้งและเริ่มบอท:
   ```bash
   cd โฟลเดอร์โปรเจกต์
   npm install --omit=dev
   npm install -g pm2
   pm2 start ecosystem.config.cjs
   pm2 save
   pm2 startup   # คัดลอกคำสั่งที่ระบบพิมพ์ให้ แล้วรันตาม
   ```
5. เสร็จแล้วบอทรัน 24 ชม. บน VPS — รีบูตเครื่องก็กลับมาเอง

> 💡 ย้ายจากเครื่องไป VPS แล้ว อย่าลืม `pm2 delete ai-bot` บนเครื่องเดิม ไม่งั้นบอทจะรันสองที่พร้อมกันและตอบซ้ำ

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| บอทไม่ตอบในช่องเลย | 1) ลืมเปิด **MESSAGE CONTENT INTENT** ใน Developer Portal (ขั้นตอน 1.4) 2) `ALLOWED_CHANNEL_IDS` ผิด/ลืมใส่ 3) บอทไม่มีสิทธิ์ View Channels ในช่องนั้น |
| `ล็อกอิน Discord ไม่สำเร็จ` | `DISCORD_TOKEN` ผิดหรือถูก Reset ไปแล้ว — คัดลอกใหม่จาก Developer Portal |
| `AI API ตอบกลับด้วยสถานะ 401` | `AI_API_KEY` ผิด หรือ `AI_BASE_URL` ไม่ตรงกับผู้ให้บริการ |
| `AI API ตอบกลับด้วยสถานะ 404` | `AI_BASE_URL` ไม่ถูกต้อง (ส่วนใหญ่ต้องลงท้ายด้วย `/v1`) หรือ `AI_MODEL` ไม่มีอยู่จริงในผู้ให้บริการนั้น |
| `AI API ตอบกลับด้วยสถานะ 429` | ใช้เกินโควตา/เรทลิมิตของผู้ให้บริการ AI — รอสักครู่หรือเติมเครดิต |
| ส่งรูปแล้วบอทตอบว่าไม่เห็นรูป | model ที่ใช้ไม่รองรับ vision — เปลี่ยนไปใช้ model ที่มองเห็นรูปได้ เช่น `gemini/gemini-3.8-flash` ผ่านคำสั่ง `/model set` |
| บอทตอบกล่องแดง "เชื่อมต่อ AI ไม่สำเร็จ" | อ่าน**สาเหตุ**ที่บอทแจ้งในกล่องเลย เช่น API key ผิด (401), model ไม่มีอยู่ (400/404), server ล่ม, โดน rate limit (429) — แก้ตามที่ระบุแล้วลองใหม่ |
| บอทออนไลน์แต่ตอบแล้ว error | ดูรายละเอียด error ในหน้าต่างคอนโซลที่รัน `npm start` อยู่ |
| พิมพ์ `/model` แล้วไม่เห็นคำสั่ง | บอทถูกเชิญโดยไม่มี scope `applications.commands` — เชิญใหม่ตามขั้นตอนที่ 2 โดยติ๊ก scope ทั้ง `bot` และ `applications.commands` (ไม่ต้องเอาบอทออก เชิญซ้ำทับได้เลย) หรือดู error ในคอนโซลตอนรีสตาร์ทบอท |
| รัน `npm` ใน PowerShell ขึ้น `running scripts is disabled on this system` | ดูวิธีแก้ในหัวข้อถัดไปด้านล่าง |

### รัน `npm` ใน PowerShell ไม่ได้ — "running scripts is disabled on this system"

อาการนี้เกิดจาก Windows ตั้งค่าไม่ให้ PowerShell รันสคริปต์ `.ps1` (ซึ่งคำสั่ง `npm` ใช้อยู่) — ไม่เกี่ยวกับโปรเจกต์นี้โดยตรง วิธีแก้มี 2 แบบ:

**แบบที่ 1: แก้ถาวร (แนะนำ)** — พิมพ์คำสั่งนี้ใน PowerShell แล้วกด Enter จะมีถามยืนยัน พิมพ์ `Y` แล้วกด Enter อีกครั้ง:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

เป็นการอนุญาตให้รันสคริปต์ในเครื่องตัวเองได้ (ระดับผู้ใช้ปัจจุบัน ไม่ต้องเป็น admin) เป็นค่ามาตรฐานที่นักพัฒนาใช้กัน

**แบบที่ 2: แก้เฉพาะครั้ง (ไม่ต้องเปลี่ยนการตั้งค่า)** — เติม `.cmd` ต่อท้ายคำสั่ง `npm` ทุกครั้ง:

```powershell
npm.cmd install
npm.cmd start
```
